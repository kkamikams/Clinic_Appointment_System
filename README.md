# Queue Clinic Management System

Queue is a web-based outpatient appointment and clinic management system designed to simplify how clinics manage patients, doctors, appointments, and medical records. The system allows patients to book consultations online while helping clinic staff organize daily clinic operations digitally and efficiently.

## Features

* Online appointment booking
* Dynamic doctor schedule and slot availability
* Patient management
* Doctor management
* Medical records management
* Follow-up appointment tracking
* Appointment status monitoring
* Activity logging
* Profile management with photo upload
* Responsive mobile-friendly interface

## Technologies Used

* PHP (Native PHP with MVC Architecture)
* MySQL / MySQLi
* HTML, CSS, JavaScript
* AJAX and Fetch API
* PHP Sessions
* bcrypt Password Hashing

## User Roles

### Admin

* Manage doctors, patients, and appointments
* Create and finalize medical records
* Track clinic activities and schedules

### Patient/User

* Register and log in
* Book appointments online
* View appointments and medical records
* Update profile information

## Security Features

* Prepared statements to prevent SQL injection
* Password hashing using bcrypt
* Session ID regeneration
* Server-side authorization checks
* File validation for uploads

## System Scope

This system is designed specifically for outpatient clinics only. Patients are consulted and treated without hospital admission or overnight stay.
